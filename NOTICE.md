# Third-party components

Our sources in this repository are under the BSD-3-Clause licence (`LICENSE`). This file lists
the third-party material in the repository, in the code exported from it and in the `plan_cert`
binary built from it. Licence texts that do not ship with a component are in `LICENSES/`.

## The `plan_cert` binary is GPL-3.0-or-later

The PDDL parser of `plan_cert` (`ML/plan_cert/src/parsing/pddl_refactor.sml`) is written with the
parser combinators of parcom (`ParserCombinators`, `CharParser`, `TokenParser`), which is under
GPL-3.0-or-later. The parser is part of every build: `ML/plan_cert/src/plan_cert.mlb` includes
`parsing/pddl_validate_plan.mlb`, which includes `ML/plan_cert/imports/parcom.mlb`, which compiles
`ML/lib/parcom/src/{parse,charparse,tokparse,langparse}.sml`. A `plan_cert` binary built from this
repository (`make build_certifier` in `ML/`) is therefore a combined work, and it may only be
distributed under GPL-3.0-or-later (`LICENSES/GPL-3.0.txt`). This includes a binary shipped
alongside this repository, such as `benchmarks/tools/plan_cert` in the TACAS artifact. The
complete corresponding source is this repository: `ML/` with its submodules `ML/lib/parcom`,
`ML/lib/cmlib` and `ML/lib/mlunta`, the exported code `ML/Check_Unsolvability.ML`, and the
theories it is generated from. Build instructions are in `Readme.md`, "Building the executable
encoder". Our sources remain under BSD-3-Clause. That licence, and the licences of the other
components linked into `plan_cert` (below), are compatible with GPL-3.0.

## Code exported from Isabelle (`ML/Check_Unsolvability.ML`)

`ML/Check_Unsolvability.ML` is generated by Isabelle's code generator (theory
`Numeric_Unsolvability_Code_Compile`, session `Numeric_Ground_PDDL_Exec_Imp`). Besides our theories
(this repository, Formal PDDL Semantics and the PDDL grounder), the theory context it is
generated in loads theories of the Isabelle2025-2 distribution and of the AFP entries below. To
the extent that the generated code is derived from those theories, their licences apply to it in
addition to ours.

- Isabelle2025-2 (sessions `HOL`, `HOL-Library`, `HOL-Imperative_HOL`, `HOL-Eisbach`, `HOL-ex`, and
  the code generator's own target-language setup): BSD-3-Clause, `LICENSES/Isabelle-COPYRIGHT`.
- Archive of Formal Proofs, release afp-2026-10-06 (entry pages at
  `https://www.isa-afp.org/entries/<entry>.html`). All entries below are under the AFP's BSD licence
  (`LICENSES/AFP-LICENSE`), except Show, which is under the LGPL 2.1
  (`LICENSES/AFP-LICENSE.LGPL`). Some files of other entries carry their own marking: in
  Deriving, the theories marked `License: LGPL` (the comparator and equality generators and
  `Derive_Manager`, used here) are LGPL 2.1, and the theories used here from Word_Lib and
  AutoCorres2 (only `lib/Subgoals.thy`, proof tooling) are marked BSD-2-Clause.
